# 記憶の外部化に必要なのは帯域ではなく索引である

## 要約

覚えたことを外に置いて、必要なときに思い出すように呼び戻す——この構想について、いま実際に人で動いている技術は「自分の脳に自分の記憶を書き戻す補助」だけである。他人に渡せる形で知識を取り出す技術も、外から知識を入れる技術も存在しない。そして呼び戻すのに要る通信量は、中身ではなく合図の分しかないので、難所は脳につなぐ線の太さではなく、外に置いた知識をどう並べておくかにある。

## ヒトで動いているのは自分の脳への書き込み補助である

USC と Wake Forest の海馬補綴（Berger, Song, Hampson, Deadwyler）が最も進んだ系統である。てんかん患者の CA3 のスパイク列を入力・CA1 を出力とする MIMO 非線形力学モデルを構築し、符号化フェーズにモデル由来の刺激を CA1 へ与えると、delayed match-to-sample 課題の成績が 37% 向上した。2024年にはこれを Memory Decoding Model へ発展させ、遅延再認課題まで改善が及ぶことを報告している。

Penn の Kahana（DARPA RAM）は別方向から同じ場所に届いている。記憶状態をリアルタイムに識別し、符号化が失敗しつつある瞬間だけ外側側頭皮質を刺激する閉ループ方式で、遅延再生が 15〜20% 改善した。**ランダムなタイミングの刺激では効果が出ない**という対照条件が本質的で、効いているのは刺激の強さではなくタイミングの選択である。Kahana が創業した Nia Therapeutics が60チャンネルの埋込み系を査読付きで検証済みで、first-in-human は2026年に予定されている。

ただしこれらが外部に置いているのは記憶内容ではなく**モデル**である。しかもモデルは被験者ごと・電極配置ごとに学習し直す必要があり、他人へは移せない。記憶補綴は知識の器ではなく較正データの塊であり、この構図は [[電脳化の格差は電極数ではなく較正データの蓄積量から生じる]] が扱う偏在と同じものである。

## 読み出せるのは意味の近傍であって逐語ではない

非侵襲側の到達点は Tang と Huth の意味再構成デコーダ（*Nature Neuroscience* 2023）である。fMRI から連続言語を再構成でき、知覚した音声だけでなく想像した発話や無音映像からも意味を復元する。しかし出力は gist であって逐語ではない。被験者ごとに十数時間の学習データを要し、被験者が心の中で別のことを考えるだけで精度が崩れる。2025年に大規模言語モデルを介した生成型再構成へ発展したが、意味レベルという解像度そのものは変わっていない。

したがって「頭の中の専門知識を吸い出して外部化する」経路は現状成立しない。外部化するなら書いて置くほうが桁違いに正確であり、この非対称は当面ひっくり返らない。

## 形式の問いは共有表象空間に落ちる

外部化したデータを文字で持つのか脳のデータ構造で持つのか、という問いには、Haxby 系の hyperalignment と Shared Response Model が事実上の答えを与えている。個人の皮質トポグラフィは特異的で、生の発火パターンは他人へ移植できない。しかし**表象幾何は個人間で共有されており**、共通空間へ回転させれば被験者間デコードが実際に成功する。既知の人物の同一性が、他人の脳活動から復号できることまで示されている。

つまり現実的な中間形式は「文字」でも「生の脳データ」でもなく、意味ベクトルである。Huth らの符号化モデルが言語モデルの埋め込みを脳活動へ写像することで動いている以上、脳側の表象と機械側の表象はすでに同じ空間で整列されている。二択に見えたものは同じ空間の別表現であり、埋め込みが橋になっている。

逆に脳固有形式で保存すると個人較正に縛られ、他人とも将来の自分とも共有できない。外部化の主たる利得——共有・検証・監査——が消えるため、脳形式で持つ動機はほぼ存在しない。

## 内容の注入は動物でも成立していない

書き込み側は読み出し側よりはるかに遅れている。Tonegawa と Ramirez の engram 光遺伝学（2013年の偽記憶形成）はしばしば記憶の植え付けとして紹介されるが、実際に行われたのは**既存の engram を再活性化し別の連合を作ること**であって、新規内容の注入ではない。命題的知識をインストールした例は動物にも存在しない。

DARPA の Targeted Neuroplasticity Training（迷走神経刺激による語学・射撃訓練の加速）も注入ではなく学習率の変調である。方向としては「ダウンロード」ではなく「早く勉強できる」であり、外部化とは別の軸にある。

## 外部化の実証知見は認知科学の側にあり、内容は厳しい

記憶の外部化を正面から扱ってきたのは神経工学ではなく認知科学である。Clark と Chalmers の拡張された心、Wegner の交換記憶、Sparrow の Google effect、Risko と Gilbert の cognitive offloading がその系譜で、意味記憶・エピソード記憶・展望記憶それぞれの技術的外部化を整理した総説もある。

ここに構想にとって最も厳しい所見がある。**外部化すると人は中身ではなく所在を覚える。さらに検索可能であること自体が自己の知識量の過大評価を生む**（illusion of knowing）。2025年の研究群は、AI による offloading が認知資源の節約と内省の侵食を同時に起こすと報告している。外部化は記憶の容量問題を解くが、知っているという感覚を実際の知識から切り離す。

## 帯域ではなく索引が律速である

想起は本来 cue 駆動のパターン補完であり、断片的な手がかりから全体が復元される。だとすれば外部化した知識を思考中に呼び戻すために BCI が運ぶべきものは内容ではなく合図であり、必要な帯域はポインタ分しかない。これは [[電極数を増やしても出力帯域は毎秒10ビットを超えない]] の上限と衝突しないどころか、毎秒10ビットで足りる数少ない応用にあたる。高帯域化を待つ理由がない点で、本プロジェクトの他の結論とも整合する。

そして「いま何を思い出そうとしているか」を検出する部品は、Kahana の閉ループが記憶状態デコードとしてすでに実装している。用途を「刺激すべき瞬間の検出」から「外部ストアを引くべき瞬間の検出」へ振り替えるだけでよい。足りないのは神経技術ではなく、外部ストア側を想起可能な粒度で索引化することである。

さらに [[生産が無限になるとき希少になるのは検証と承認である]] と接続すると、外部化した知識を自分が本当に知っていると請け合えるかという問題が残る。offloading が illusion of knowing を生むという実証は、承認が希少財になるという予測と同じ場所を指している。外部化が進むほど知識の所有と承認は分離し、人間の側には承認だけが残る。

## 未検証

海馬補綴の 37% は delayed match-to-sample という限定的な課題での短期記憶成績であり、専門知識のような意味記憶へ一般化する根拠はない。被験者はいずれもてんかんで電極を留置中の患者で、健常者への外挿は未確認。Nia Therapeutics の first-in-human は予定であって結果ではない。

hyperalignment による被験者間デコードは、同一刺激を全員が見ている条件下で表象幾何を揃えたものである。各人が別々に蓄積した専門知識——共通の刺激系列を持たない表象——を同じ手法で整列できるかは検証されていない。「意味ベクトルが現実的な中間形式である」は本ノートの解釈であって、いずれの論文の主張でもない。

「想起は cue 駆動なのでポインタ分の帯域で足りる」も本ノートの推論である。外部から呼び戻した知識が単なる検索にとどまらず**推論の作業記憶へ統合されるか**を直接調べた研究は見つけられなかった。想起と検索が現象として別物である以上、ここが構想の成否を分ける可能性が高い。

cognitive offloading の実証は主にスマートフォンや検索エンジンを対象としており、BCI 経由の低遅延な呼び戻しでも同じ illusion of knowing が生じるかは未検証。HRL の tDCS による技能転写（2016年）は当時広く報じられたが、効果量と再現性の評価を追えていないため本文には採らなかった。
