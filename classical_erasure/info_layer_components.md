# 情報層の構成部品解説（初学者向け補足）

**作成日**: 2026年7月28日　**改訂日**: 2026年7月29日（駆動段を74HCT595からTC4427に変更。経緯は[[cell_driver_choice]]）
**関連文書**: [[architecture]]（3.1節・3.2節・5節）、`components.md`（2節）、[[回路解説_初学者向け]]（GPIO＝スイッチの節）、[[pi_pico_role_separation]]、[[cell_driver_choice]]（駆動段選定の経緯・導出）

## 1. マイコン以外の部品の役割

情報層（`components.md`2節、[[architecture]] 3.1節）に出てくる部品のうち、マイコン（Raspberry Pi Pico）以外の役割を整理する。

| 部品 | 役割 |
|---|---|
| Raspberry Pi（マイコンではなくOS付き小型PC） | MQTT通信、乱数取得、平文をtmpfsのみに保持（[[architecture]] 3.1節）。Picoとの役割分業の詳細は[[pi_pico_role_separation]] |
| TC4427（デュアルMOSFETドライバ） | Picoの GPIO を直接受け、セルのコンデンサを駆動できるだけの電圧・電流を供給する本体。1個で1bit分（$C_b$・$\bar{C_b}$）を賄う（[[cell_driver_choice]] 1〜2節） |
| デカップリングコンデンサ（100 nF、IC1個ごと） | IC切替時の瞬間的な大電流要求による電圧降下（グラウンドバウンス）を、ICのすぐそばの小さな電荷タンクで吸収する |
| バルクコンデンサ（10 µF、12V系） | デカップリングより広い範囲・長い時間スケールの電力ゆらぎを吸収する、より大きなタンク |
| 制御基板（FR4 2層） | 上記すべてを固定・配線する土台。能動部品ではない |

**旧版との違い**：以前は74HCT595（シフトレジスタ）が「信号を多数の出力に分配する役割」と「セルを駆動する役割」の両方を1個で担っていたが、595はセルを直接駆動するには力不足（5V・16.7mA/ch）で、これがビット数を64に縛る原因になっていた（`components.md`0節）。TC4427への変更で「駆動する役割」は強化されたが、8bit規模ではPicoの空きGPIO（概算18〜20本）で直結できてしまうため、**「分配する役割」自体がそもそも不要になった**。つまり今回は部品を強くしただけでなく、段を1つ削れている。

## 2. なぜシフトレジスタが要らなくなったか

「Picoの3本の信号線を多数の出力に展開する」というシフトレジスタの仕事は、出力数がPicoの持っているGPIOの数を上回るときに必要になる。8bit（ハーフセル16個）なら必要な出力線は16本で、Picoの空きGPIO本数に収まるため、**Picoが直接16本のGPIOでTC4427を駆動すればよく、分配段を挟む理由がない**。

ビット数を増やしてPicoのGPIOが足りなくなった場合は、シフトレジスタが「TC4427の入力（ロジックレベル、電流はほぼ食わない）」を駆動する形で復活する。この場合、595の出力の弱さは問題にならない——595が弱いことが問題だったのは、595が**セルを直接**駆動していたときだけである。詳しい部品数の試算は[[cell_driver_choice]] 3.5節を参照。

## 3. なぜドライバとコンデンサは一体部品化されないか

デカップリング/バルクコンデンサは駆動ICの型番に関わらず**あらゆる種類のICに共通して必要な電源安定化の作法**（配線の寄生インダクタンスに起因する物理的要求）。また100nF〜10µFという容量値は面積を要するため、ICのシリコンダイ内部に集積するのは非現実的。ゆえに「ドライバ内蔵コンデンサ」という部品は存在せず、存在する意味もない。

## 4. TC4427と消去セルの接続

TC4427の出力ピンは、中継用のトランジスタやリレーを介さず、**直接**消去セルのコンデンサを充放電する（[[architecture]] 3.2節）。Picoの足が持つ「ソフトで切り替えられるスイッチ」という性質（[[回路解説_初学者向け]]冒頭）を、TC4427の出力ピンもそのまま引き継いでおり、これが本装置で唯一の能動部品にあたる。専用の中継段を置かない設計であることが、部品点数を抑える一方で、セルとの配線を「セル数×2本」（[[architecture]] 5節）という規模にしている——ここは74HCT595のときと変わらない構造で、変わったのは駆動段の型番と、その手前にあったシリアル分配段の要否だけである。
