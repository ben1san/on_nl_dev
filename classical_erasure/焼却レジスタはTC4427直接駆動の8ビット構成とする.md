# 焼却レジスタはTC4427直接駆動の8ビット構成とする

データを消す部分の、実際の部品と配線の決まり。
専用のスイッチは置かず、ドライバICの出力そのものがコンデンサを充放電する。
8ビット分＝16組のコンデンサと抵抗を並べ、12Vで駆動して約1Wの熱を出す。

**採用方式**: 相補容量セル ＋ TC4427直接駆動。設計原理は[[発熱量の中身非依存性は回路トポロジーで保証する]]、熱の受け渡しは[[接触プレートはアルミ単板とし断熱は実測後に決める]]、遮断系は[[過熱遮断はハードウェアのみのループで完結させる]]を参照。

---

## 確定値

1セル（1ビット）＝相補な2組の $(R, C)$。1サイクルは $(0,0) \to (d,\bar d) \to (0,0) \to (r,\bar r) \to (0,0)$ の4遷移で、各遷移でちょうど1個のコンデンサが充電または放電する。

| パラメータ | 値 | 備考 |
|---|---|---|
| 駆動段 | **TC4427**（デュアルMOSFETドライバ、DIP-8、2ch/個） | 1個で1bit分（$C_b$・$C_{\bar b}$）を賄う |
| 動作電圧 $V$ | **12 V** | TC4427は4.5–18 V対応。18 Vまで伸び代あり |
| セル容量 $C$ | **68 nF**（ポリエステルフィルム ±5% 50V） | E系列に71 nFは存在しない。総発熱量には影響しない |
| 直列抵抗 $R_{ext}$ | **120 Ω 1/4 W** | ドライバ $R_{on}$ と直列。アルミ板に実装する設計原則上、下げられない |
| ビット数 | **8 bit 並列**（16ハーフセル） | Picoの空きGPIOに直結でき、シフトレジスタが不要 |
| 時定数 $\tau$ | **9.358 µs（実測）** | 充電9.322 / 放電9.394 µs、非対称度0.8% |
| 1相の長さ | $4\tau$ ＝ **37.4 µs** | MicroPythonの `sleep_us(30)` で実測37.5 µs（4.01τ） |
| $\alpha$ | **18.9 µJ/bit** | $2CV^2\tanh(2)$。4τ打ち切りによる3.6%減を含む |
| サイクル周波数 | **6.68 kHz** | $1/(16\tau)$ |
| 総散逸 | **約1.0〜1.1 W**（うち掌側 ~0.95〜1.0 W） | 幅は $R_{on}$ の不確かさによる |
| スループット | 53 kbit/s ≈ 6.7 kB/s | 1 MB を約157秒 |

**ビット数8bit・$C$ 68 nF・$V$ 12 Vは固定する。** 

$\alpha$ の精度は $C$ の精度だけで決まり、$R$ の誤差は熱量に効かない。16個平均で誤差は $1/\sqrt{16}\approx25\%$ に落ち、フィルムの初期公差±5%を踏まえればINA260較正で吸収できる範囲に収まる。

### 実測時定数について

$\tau$ は等価時間サンプリング（同じ遷移を繰り返し、測定タイミングを1 µsずつずらす）でPico自身のADCから取得した。決定係数は充電0.9997・放電0.9999できれいな単一指数になっている。**充放電の非対称度0.8%**は、TC4427のプルアップ側とプルダウン側の $R_{on}$ がほぼ等しいことを意味し、4相すべてを同じ待ち時間で回せる根拠になる。

ただしこの測定は**5V駆動**で行った。$R_{on}$ は電源電圧に依存するため、12Vでは $\tau$ がやや短くなる。$\tau=RC$ からは $R$ と $C$ を分離できず（$C=68$ nFなら $R=138\,\Omega$、$R=127\,\Omega$ なら $C=74$ nF）、総散逸 $P$ は $R$ だけで決まるため、上表の1.0〜1.1 Wという幅はここから来ている。

## 回路

### TC4427のピン配置

Microchipデータシート DS20001422G で確認済み。8-Pin PDIP/SOIC/MSOP、両チャンネルnon-inverting。

```
        ┌─────∪─────┐
  NC  1 │            │ 8  NC
 IN A 2 │            │ 7  OUT A
  GND 3 │  TC4427    │ 6  VDD
 IN B 4 │            │ 5  OUT B
        └────────────┘
```

**入力しきい値**は4.5–18Vの全動作範囲で共通の絶対値（VDD比ではない）で、$V_{IH}$（Logic '1' 最小）＝2.4 V、$V_{IL}$（Logic '0' 最大）＝0.8 V。Pico GPIO（3.3V/0V）はレベルシフタなしで直接IN A/IN Bを駆動できる。

### 1ビット詳細回路（TC4427 1個 ＝ 2ハーフセル）

```
                                  +12V_cell
                                    │
                        ┌───────────┼───────────┐
                        │  NC(1)          NC(8) │
                        │          VDD(6)       │
 Pico GPIO(2n)  ────────┤IN A(2)                │
 （bitn の「1」側）      │            OUT A(7)  ├──[R_ext 120Ω]──●──[C 68nF]──● GND  … Cb（ビット=1側）
                        │      TC4427           │
 Pico GPIO(2n+1)────────┤IN B(4)                │
 （bitn の「0」側）      │            OUT B(5)  ├──[R_ext 120Ω]──●──[C 68nF]──● GND  … C̄b（ビット=0側／相補）
                        │                        │
                        │          GND(3)        │
                        └───────────┬────────────┘
                                    │
                                   GND
```

$R_{ext}$（120Ω）とTC4427出力段の $R_{on}$ が直列になる。$C$ の充放電エネルギー $\frac12CV^2$ が $R$ でほぼ全て熱に変わり、その $R$ がアルミ板の上に載っている——熱源とデータ消滅点が同一素子であるという主張は、この1枚に集約される。

### 全体結線（8bit・16ハーフセル、シフトレジスタなし）

```
Raspberry Pi Pico 2                TC4427 ×8                  セル ×16
 GP0 ──IN A┐
 GP1 ──IN B┴─ #1（bit0）─OUT A/OUT B─→ R-Cペア×2（Cb0 / C̄b0）
 GP2 ──IN A┐
 GP3 ──IN B┴─ #2（bit1）─OUT A/OUT B─→ R-Cペア×2（Cb1 / C̄b1）
  :            :                              :
 GP14──IN A┐
 GP15──IN B┴─ #8（bit7）─OUT A/OUT B─→ R-Cペア×2（Cb7 / C̄b7）
```

16本のGPIOをTC4427×8個のIN A/IN Bへ直結する。GND・VDD（12V）は8個で共通バス。**IN AをGP偶数、IN Bを奇数**に揃えてあるので、ソフト側で「bit $b$ の1側＝GP(2$b$)、0側＝GP(2$b$+1)」と書け、相補ペアがそのままビット演算になる。

### 電源・遮断の系統

```
12V ACアダプタ → DCジャック
   ├──→ 降圧コンバータ(12V→5V) → Pi / Pico（常時給電、遮断の影響を受けない）
   └──→ [Pch MOSFET] ← コンパレータ ← NTC#1
            └──→ [INA260] ──→ +12V_cell ──→ TC4427 #1〜#8 の VDD(6)
```

Pi/Pico用の5V系統はセル遮断より上流から分岐するので、遮断中も制御・監視は続く。ただし**現状の実装ではセル用12Vがアダプタ直結になっており、この遮断経路を通っていない**（[[過熱遮断はハードウェアのみのループで完結させる]]）。

### 情報層（制御）

| 品目             | 型番                  | 数量  |
| -------------- | ------------------- | --- |
| マイコン           | Raspberry Pi Pico 2 | 1   |
| セルドライバ         | **TC4427** DIP-8    | 9   |
| デカップリング        | 100 nF（リード品）        | 10  |
| バルクコンデンサ（12V系） | 10 µF 電解            | 3   |
| 制御基板           | ユニバーサル基板（穴あき、汎用）    | 1   |

**制御基板はユニバーサル基板に一本化し、これを最終構成とする。** 量産発注もFR4カスタム基板の発注も行わない。部品は手ハンダの点対点配線で実装する。

Raspberry Piは所持品。MQTT受信 → tmpfs（`swapoff -a` 必須）→ UART/SPIでPicoへ渡す。不揮発媒体には一切触れさせない。

### 消去セル

| 品目      | 仕様                                  | 数量  |
| ------- | ----------------------------------- | --- |
| セルコンデンサ | **68 nF 50 V ポリエステルフィルム ±5%**（リード品） | 20  |
| 直列抵抗    | **120 Ω 1/4 W**（axialリード品）          | 20  |

**フィルムコンデンサを採用する。** X7RはDCバイアスで容量が落ちるため「容量変動は相補ペアの両側で同一に効くので対称性は保たれる、絶対値のずれはINA260で較正する」という注記が必要になる。ポリエステルフィルムはDCバイアスによる容量低下がほぼ無く温度特性も安定なので、**その注記自体が要らなくなる**。初期公差も±5%（X7Rは±10〜20%）と良く、$\alpha$ がセッション中に動かないぶんINA260較正の信頼性が上がる。

**抵抗は1/4 W。** 1本あたり平均電力は12V動作時で約61 mW。

**ピーク電流**は1チャネルあたり $V/R\approx12/130\approx92$ mA。TC4427のピーク定格1.5Aに対して約6%で、GNDピン定格の逼迫は起きない。

### 電源

| 品目               | 仕様                      | 数量  |
| ---------------- | ----------------------- | --- |
| ACアダプタ           | 12 V 2 A センタープラス（筐体外設置） | 1   |
| 降圧コンバータモジュール     | 12V→5V、Pi/Pico用         | 1   |
| DCジャック + ヒューズホルダ | 側面パネル実装                 | 1   |

**電源は12V単一系統**とし、Pi/Pico用の5Vはオンボードの降圧コンバータで生成する。外部アダプタ・配線出口を1系統にまとめられる。配線出口は側面に12V DCジャック1系統のみ。

⚠️ **5VはPicoのVSYS（物理39番）へ入れる。VBUS（40番）は使わない。** VBUSはUSBの5Vに直結しているため、外部電源を繋ぐとUSBと押し合ってホスト側を壊す可能性がある。VSYSは内部ショットキー経由なのでUSBへの逆流が阻止される。降圧コンバータ出力とVSYSの間にショットキーダイオード（1N5817等）を1本入れておくと、開発中にUSBと12Vを同時に挿しても高い方が勝つだけで済む。

## ファームウェアに課される制約

**ピン割り当て**: GP0〜GP15＝16ハーフセル駆動、GP16/GP17＝Piとの UART0、GP18＝コンパレータ出力モニタ、GP20/GP21＝INA260のI2C、GP26/GP27＝NTC読み取り（ADC）。

**GPIOの書き込み方は自由に選べない。** 実測すると `Pin.value()` で1ピンずつ書く方式は2ピンで8.24 µs/相かかり、16ピンに拡張すると概算55〜66 µs/相となって設計値37.4 µsを超過する。**SIOレジスタ（`GPIO_OUT`、RP2350では `0xd0000010`）へ32ビットワードを1回書く方式**なら、ピン数に依存せず3.32 µs/相で済む。16ピンが同時に切り替わる点も、1ピンずつずらして書くより相補ペアの対称性の観点で素直である。

**PIOはスループットのためには不要。** 素のMicroPython＋SIO書き込みで `sleep_us(30)` → 37.5 µs/相（4.01τ）と設計値に届く。PIOの価値は速度ではなくジッタの排除にあり、組み立ての律速にはならない。ジッタは遅れる方向なら無害だが、**4τより短い相が混じると充電が完了せず残留電荷が履歴に依存し始める**ため、短くなる方向のずれだけは避ける。

⚠️ **RP2350のエラッタE9**: 入力＋内部プルダウンでパッドが浮いていると、入力バッファがラッチして約2.1Vに張り付きHIGHと読めてしまう。内部プルダウンに依存した判定を書かないこと（外部プルダウンは8.2 kΩ以下）。RP2040には無いRP2350固有の問題である。

## 実装方法と接続の作法

RとCを直列にハンダ付けしたペアを16組作り、各ペアの両端をリボンケーブルで制御基板まで引き出す。**Rをアルミ板へ固定する方法は未決**で、「R本体のみ熱伝導両面テープで貼りCは宙に浮かせる」案は棄却して再検討中である（[[接触プレートはアルミ単板とし断熱は実測後に決める]]）。発熱するのはRだけなのでC側は熱的にどう扱ってもよく、Cとの電気的接続は単純な配線で足りる。

**デカップリング100 nFは各ICの3番（GND）と6番（VDD）を裏側で橋渡しする形で直付けする。** 表面の穴を消費せず、GND–VDD間のループが最短になる。TC4427の出力は数十nsで切り替わり瞬間的に約92 mAの電流ステップが出るため、この最短ループが効く。
