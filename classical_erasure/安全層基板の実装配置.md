# 安全層基板の実装配置

プレートが熱くなりすぎたときに、ソフトウェアを介さず電源そのものを切る回路の作り方をまとめたもの。温度センサの線が外れた場合や部品が壊れた場合も含めて、**どこが異常でも必ず「切る」側に倒れる**ようにしてある。95×72mmのユニバーサル基板1枚に、どの穴へ何を挿すかまで書いてある。

関連文書：機能ブロックと設計原則は[[architecture]] 3.4節、部品表と熱設計は[[components]] 4節、制御基板側の回路図は[[circuit_schematic]]、異常時の倒れ方の指摘は[[implementation_risks]]。

---

## インバータ段を入れる

[[components]] 4節が「1センサ構成のままにするか、インバータ段を足すかは未決定」としていた点を、**インバータ段を入れる**方に決めた。追加はNPN 1個と抵抗2本だけで、これがないと次の3つの故障がすべて「遮断されない側」に倒れる。

| 故障 | インバータなし | インバータあり |
|---|---|---|
| NTC断線 | 「冷たい」と読めて遮断されない | 遮断 |
| コンパレータ出力のLOW固着 | 遮断されない | 遮断 |
| 2個目のNTCによる冗長化 | ワイヤードANDになり両方が検知しないと切れない | どちらか1つで切れる |

却下したのは**コンパレータ出力でPchゲートを直接駆動する案**である。部品は減るが、**1つのしきい値では過熱とNTC断線の両方を捕まえられない**。NTCは断線すると抵抗が無限大になり、これは常に「いちばん冷たい」側の電圧に対応する。過熱で振れるのは反対側なので、分圧の上下を入れ替えても片方しか取れない。参加者が触れる装置の最後の砦である以上、この非対称は許容できない。

インバータを入れると、余っていた**TA75393Pのもう片方の回路をNTC断線検出に使える**ようになり、1個のICで両側を挟める。

## 回路

```
12V ─┬─ NTC#1 ─┬── node_T ──┬── R1 10k ── GND
     │          │            ├── U1 pin2 (IN A−)   過熱検出
     │          │            └── U1 pin5 (IN B+)   断線検出
     ├─ VR1 ── wiper ─┬─ U1 pin3 (IN A+)   7.81V ≒ 42℃
     │                └─ R2 100k ── X       ヒステリシス 3.1K
     ├─ VR2 ── wiper ─── U1 pin6 (IN B−)   2.0V ≒ 断線判定
     ├─ U1 pin8 (VCC)、C1 100nF を pin8–pin4 間に
     ├─ R3 10k ── X                         Xプルアップ
     ├─ R5 10k ── Q1 gate                   ゲートプルアップ
     └─ Q1 source

U1 pin1 (OUT A) ─┬─ X ─┬─ C3 100nF ─ GND   起動遅延・ノイズ除去
U1 pin7 (OUT B) ─┘      └─ R4 10k ─ Q2ベース

Q2 2N3904: エミッタ→GND、コレクタ ─ R6 1k ─ Q1 gate
Q1 drain ─ INA260 ─ +12V_cell → 制御基板
```

正常時のみ両コンパレータが開放してXが12Vになり、Q2が導通してゲートを引き下げ、Q1が通電する。過熱・NTC断線・NTC短絡・コンパレータ故障のいずれでもXが落ち、R5がゲートを12Vへ持ち上げて遮断する。**全系統が正常なときだけ通電する**向きになっている。

分圧は `12V → NTC → node_T → 10k → GND` の向き（NTCが上）。103AT-11（B=3435）の計算値で42℃＝7.81V、感度90mV/K、0℃＝3.10V。V_ref2を2.0Vに置けば正常温度域を誤検知せず、断線（0V）だけを拾える。NTC短絡（12V）は過熱側のコンパレータが拾う。

**R2は100kΩ**。[[components]] 4節の「100kΩで3.1K」はトリマ側（テブナン2.4kΩ）へ帰還させる前提の値で、この構成はそのとおりになっている。帰還先をnode_T側（テブナン3.5kΩ）に変える構成では150kΩが必要になるので、値だけ流用してはならない。

C3は起動時の保険でもある。R3との時定数1msでXの立ち上がりが遅れるため、コンパレータが判断を終える（µsオーダー）まではQ1が入らない。

## 基板と座標系

秋月 AE-B2 TH、95×72mm、**35列 × 25行**。座標は **[列, 行]** の順で書く。**[1,1]が左下、[35,25]が右上**。1つ目は1〜35、2つ目は1〜25までしか取らないので、2つ目が26以上なら読み違えである。

部品は番号のない面に挿し、**バスと配線は番号のある面**に置く。配線が30本近くあり、その大半が空き穴どうしを結ぶ作業で座標を必要とするため。裏返すと列1が右端に来るので、作業前に[1,1]の角へ油性ペンで印を付けておく。極性のある部品（端子台・D1・INA260）は、挿す前に部品面へ油性ペンで向きを書いておくと逆付けを防げる。

以下で「**ノード**」「**クラスタ**」と呼ぶものは部品ではない。ユニバーサル基板にはパターンがないので、3本以上が集まる合流点はすずメッキ線を数穴渡して自分で作る。ゲートノード[9,21]〜[12,21]とnode_Tクラスタ[8,9]〜[11,9]がこれにあたり、どちらも**1穴に1接続だけ**を割り当ててあるので、座標表とテスターの当て先が一対一で対応する。

## バス

7本すべて横一直線（行が固定で列が動く）。先に引いてから部品を載せる。

- [x] **電力GND** — [2,25] 〜 [34,25]
- [x] **12V_IN** — [2,23] 〜 [13,23]
- [x] **セル出力** — [24,19] 〜 [31,19]（**[32,19]で切ってある**。当初[33,19]まで引いたが、それだとセル出力端子台の2ピン[31,19]・[33,19]が同じ線を共有して短絡する）
- [x] **判定12V** — [4,11] 〜 [32,11]
- [x] **判定GND** — [4,5] 〜 [32,5]
- [x] **V_ref1** — [15,3] 〜 [18,3]
- [x] **X** — [21,8] 〜 [26,8]

**判定GNDと電力GNDは [4,5]→[4,25] の1本でだけ繋ぐ。** これがこの基板で最も重要な配線判断である。セル電流はピーク0.74Aのパルス（[[implementation_risks]]）で、その戻りが判定GNDを通ると90mV/Kの感度に対して閾値温度が実測で揺れる。**判定帯を縦断する線は**このスター接地と、後述のゲート配線の2本だけ（電力帯・分岐帯には`[3,15]→[3,23]`や`[33,19]→[33,25]`など他にも縦線がある）。

スター点の位置に意味がある。12V入力端子台のGNDは`[4,24]→[4,25]`、スター接地は`[4,5]→[4,25]`で、**両方とも[4,25]という同じ穴に集まる**。セルの戻り電流は[33,25]から電力GNDバスを列4まで走るが、判定GNDがぶら下がるのはその終点なので、**バス上のIR降下が判定GNDの基準に一切乗らない**。電源の出入口を基準点に取るということで、この一致は崩してはならない。

## 部品位置

**電力帯**

- [x] **12V入力端子台 2P** — [2,24]=+12V、[4,24]=GND
- [x] **Q1 IRF9540** — S=[7,21] D=[8,21] G=[9,21]
- [x] **ゲートノード** — [9,21] 〜 [12,21]
- [x] **R5 10kΩ** — [7,22] ↔ [11,22]
- [x] **INA260** — 1×8ピンソケットを [15,20]〜[22,20]（**電力ピンを列15側、ロジックピンを列22側**に向ける）
- [x] **セル出力端子台 2P** — [31,19]、[33,19]

Q1はタブがドレイン。寝かせてネジ留めし、放熱器は不要（0.117Ω×0.1Aで損失1.2mW）。ハンダ前にダイオードモードで赤＝ドレイン・黒＝ソースの導通を確認する（Pchのボディダイオードの向き）。

INA260は8パッドにピンヘッダを立てて縦置きにするので、占有は8穴で済む。行20を選ぶのは、**この行だけが列1から35まで完全に空いている**ため。すぐ上の行21はQ1とゲートノード（列7〜12）、すぐ下の行19は列24からセル出力バスが始まるが、どちらも列15〜22には掛からない。向きは、VIN+がQ1ドレイン[8,21]から来て、VIN−がセル出力バス[24,19]へ抜け、ロジック4本が右下の信号ヘッダへ下りる流れに合わせたもの。個々のピンがどの穴に入るかは**現物のシルク順に従う**（Adafruit系とクローン系で並びが違う）。

**セル出力端子台のGND側は未確定。** バス定義 [24,19]〜[33,19] が端子台の2ピン（[31,19]・[33,19]）を両方含んでおり、このままでは2ピンとも+12V_cellになる。配線節にも[33,19]から電力GNDへ行く線がない。バスを[31,19]止まりにして[33,19]を電力GNDへ落とすのが素直だが、[33,19]→[33,25]という3本目の縦線が生まれる。セル電流の戻りをどこへ落とすかはこの基板で最も影響の大きい判断なので、**通電前に確定させる**。

**分岐帯**

- [x] **端子台 2P**（降圧へ12V送り） — [3,15]=+12V、[5,15]=GND
- [x] **端子台 2P**（降圧から5V受け） — [9,15]=GND、[11,15]=5V
- [x] **D1 ショットキー 1A** — アノード=[16,15]、**カソード（帯）=[20,15]**
- [x] **5V出力端子台 2P**（Picoへ） — [23,15]、[25,15]

**降圧コンバータは基板に載せない。** 7セグ表示とS1ボタンを持つ個体で約28×50mmあり、この基板に置く場所がない。四隅のネジ穴と入出力ネジ端子で単体固定する前提の作りなので、M3スペーサで筐体内に別置きし、上の2つの端子台と電線で繋ぐ。表示器・S1・調整トリマにアクセスできる向きで固定する。行13〜14と行16〜17は配線の逃げ場として空けておく。

**端子台5個はすべて同一品でよい。** 5個とも同じ行の2穴おき＝5.08mmピッチで、最も重いのが12V入力とセル出力のピーク0.74Aパルス。市販の5.08mm 2P品は10A級なので定格の1割も使わない。選定条件は2つだけで、5.08mm（＝2.54の倍数）ピッチであること、**ネジが上面にある型**であること。前面ネジ型は向きがドライバのアクセス方向まで決めてしまう。連結型を横に繋いで4P化すると累積誤差で穴に合わなくなるので、単体の2Pを5個使う。座標が同じ行の2穴なのでピン列は横向きに固定され、選べるのは電線が上から入るか下から入るかだけになる。12V入力は上（上端側、行24から上端まで約8mm）、セル出力も上（下へ向けると0.74Aパルスの線が判定帯の真上を通る）。分岐帯の3個は行13〜14の逃げ場へ下向きに出して左端へ束ねるが、最終的な向きは降圧コンバータと制御基板の筐体内配置で決まる。電線は予備半田せずに棒端子（フェルール）で締める。半田はクリープして緩む。

IC本体が行8〜9・列16〜19を覆うのでその8穴は使えない。トリマは両端の2本が入れ替わっても動作は同じで、変わるのは回す向きだけ。**真ん中のワイパーだけ間違えなければよい**。三角配置の個体ならワイパーが1行ずれる。

**この基板に載るNTCはNTC#1だけである。** 3.3V駆動のNTC#2（アルミ板・デューティ制御用）とNTC#3（室温補正用）は[[情報層基板の実装配置]]へ移した。両者は[[components]] 4節の通りPicoのADCが読むソフト系統で、コンパレータにも遮断にも関与しない。ここに置くと分圧ノード（10k‖NTCで約3.5kΩ）をリボンケーブルで往復させることになり、同じ筐体内をピーク0.74Aのパルスが流れる以上それは避ける。Picoの隣で完結させればノードがケーブルに出ず、基準もPicoのAGNDになる。信号ヘッダが5ネットで収まるのもこの分離の結果である。

以前この節には`3.3V側NTC分圧 10kΩ×2 — [22,2]↔[22,5]、[27,2]↔[27,5]`という行があり、実際にはその座標へNTCが直付けされていた。移設にあたって4本のリードを外す。外すときの注意は2つで、**[22,3]はR2の端＝ヒステリシス帰還ノード**で[22,2]の2.54mm隣にあるためブリッジさせないこと、**[22,5]・[27,5]は判定GNDバスの穴**なので吸取線で短時間に当ててバスのすずメッキ線ごと持ち上げないこと。外したあと**[22,5]↔[4,5]の導通が残っていることを必ず確認する**。4穴は空きに戻り、[22,5]・[27,5]は使われないバス穴になるだけで他への影響はない。

信号ヘッダの割り当ては次の通り。列34を全部GNDにすると[34,1]〜[34,5]を1本のすずメッキ線で作れ、フラットケーブル上で各信号にリターンが隣接する。相手側（制御基板の2×5ヘッダ）も同じ並びにしてあるので、ストレートのフラットケーブルで繋がる（[[情報層基板の実装配置]]）。

| | 列33 | 列34 |
|---|---|---|
| 行1 | 3.3V | GND |
| 行2 | SDA (GP20) | GND |
| 行3 | SCL (GP21) | GND |
| 行4 | GP18 | GND |
| 行5 | 予備 | GND |

**平型ではなく箱型を使う。** ここに乗るのは3.3V・GND・GP20・GP21・GP18で、180°逆に挿すと3.3VがGPIOへ、GNDが3.3Vへ当たってPicoが死ぬ。平型ピンヘッダには防ぐ機構が何もない。この作品は既にIDCコネクタとフラットケーブルを多用している（[[enclosure_fit_review]]）ので部品の統一にもなる。ただしシュラウドはピン列より各辺3〜4mm外へ張り出し、行1から基板下端までは約5.5mmしかない。現物が入らなければ**[33,3]〜[34,7]へ2行上げる**（列33〜34の行6〜10は空いている）。箱型が手に入らない場合は、平型の1ピンを抜いてキーイングする。必要なネットは5本なので10ピン中1本潰す余裕がある。

- [x] **NTC#1（基板外の部品）** — リード2本の着地点が `[6,11]`（判定12Vバス）と `[8,9]`（node_Tクラスタ）。**この2穴の間に線は通らない**

**node_TがU1のpin2とpin5、トリマがpin3とpin6**である。直接駆動案とは逆なので、値だけでなく入力の割り当てごと読み替えてはならない。

**NTC#1は基板に載らない。** アルミ板に貼り付ける温度センサで、筐体内を這って基板へ戻る。上の行は「2穴を繋げ」ではなく「基板外から来た2本のリードをそれぞれこの穴へ挿せ」の意味で、これで `判定12V(行11) → NTC#1 → node_T(行9) → R1 10k → 判定GND(行5)` の分圧が閉じる。NTCが挿さるまで分圧は下半分しか存在せず、node_Tを測っても0Vにしかならない。NTCは無極性なので2本のリードは入れ替えてよい。103AT-11（B=3435）の実効値は42℃で5372Ω、node_T = 12 × 10k/(10k+5372) = 7.81V、0℃では28.7kΩで3.10V、消費は12/15372 = 0.78mAより3.3mWで、いずれも上の計算値と一致する。

本体のリードは数cmしかないので延長が要る。その継ぎ目が「直付け＋収縮チューブ」で、**基板側の入口はホットボンドで固定する**。ユニバーサル基板のランドは引っ張ると剥がれ、[8,9]が浮けばその瞬間は断線として正しく遮断側に倒れるが、設営のたびに遮断されては使えない。**延長した2本はツイストする。** node_Tをテブナン3.5kΩ・90mV/Kでコンパレータへ運ぶ線が、ピーク0.74Aのパルスと同じ筐体内を通るため。コネクタにしないのは、断線検出を入れてもなお抜けやすい接続を作る理由がないため。

**INA260**は電流経路をネジ端子とVIN+/VIN−パッドのどちらから取ってもよい（並列で、流れるのは約70mA）。VIN+がQ1側＝上流、VIN−が制御基板側＝下流で、逆にすると$\int VI\,dt$の積算が負になる。**ロジック電源は必ず3.3V**（Picoの36番）から取る。5Vを入れるとI2Cのレベルが5VになりGP20/GP21を壊す。I2Cプルアップはブレークアウト側に載っている。

**降圧コンバータ**の+VINは**Q1より上流の12V_INバス**へ繋ぐ。安全系がセルを遮断してもPi/Picoは動き続ける必要があるため（[[circuit_schematic]] 3節）。出力はD1経由でPicoの**VSYS（39番）**へ。VBUS（40番）はUSBの5Vに直結しているので外部電源を繋ぐとホスト側を壊す。

D1は1Aショットキーで足りる。この位置を流れるのは5V側の負荷電流だけで、Pico単体なら約50mAしかない。仮にショットキーでなく普通のシリコンダイオードでも、VSYSは1.8〜5.5Vを受けるので0.7V降下しても動作する。

## 調整と保護

**降圧コンバータの出力は、Picoに繋ぐ前に必ず合わせる。** このモジュールは可変出力で初期位置が不定であり、12V近くがそのまま出ることもある。出力側に何も繋がない状態で12Vを入れ、テスターでVOUT+とVOUT−の間を測りながら**5.0〜5.2V**にしてから接続する。5.2VにすればD1の降下を引いてVSYSが約4.9Vになる。上限は5.5V。表示器の値は目安で、確定はテスターで取る。

**トリマは通電した正常（冷）状態で調整する。** R2の帰還がV_ref1をわずかに持ち上げるため、無通電で合わせるとずれる。VR2を先に2.0Vへ、VR1は後からアルミ板にNTCを貼り、基準温度計と突き合わせて42℃で切り替わる点に合わせる。計算上のwiper電圧7.81Vは出発点にすぎない。合わせたらネジにホットボンドを一滴垂らして固定する。設営の振動でハードカット温度が動くと安全機構の意味が薄れる。

**ヒューズは2Aではなく1Aスローブロー。** アダプタが12V 1.5Aなら、2Aのヒューズは基板が短絡してもアダプタ側の保護が先に落ちるだけで保護にならない。通常消費は約110mA（Pico単体構成）で、Pi Zero 2 Wを足しても385mA。スローブローにするのは降圧コンバータの入力コンデンサへの突入で誤って飛ぶのを避けるため。セル側のバルク30µFへの突入は、Q1が起動時にOFFから始まるので電源投入の瞬間には流れない。

NTC#1は12V駆動で約3.3mWを消費し、静止空気中なら2K以上の自己発熱誤差になる。アルミ板に熱伝導接着すれば実効放熱定数が上がって実害は小さくなり、いずれにせよ現物合わせの較正に吸収される。**板に貼った状態で調整すること**が条件になる。

## 組立順と途中検証

順序の原則は[[components]] 8節と同じで、**背の低い部品から**、**不可逆な工程と壊れうる工程を後ろに回す**。この基板に固有の要点は、**判定帯だけを先に完成させてQ1を載せる前に検証を通す**ことにある。判定帯が正しければコンパレータ出力を見るだけで全異常が確認でき、その段階では電力段が存在しないので、配線を間違えていても壊れる部品がない。

個々の部品と配線は前の2節でチェックする。ここは**工程の区切りと、部品リストに現れない作業**だけを並べたもの。いずれも雛形であり、チェックの状態は各自の手元で付ける。

- [ ] バス7本（「バス」節）
- [ ] スター接地 `[4,5]→[4,25]` を1本だけ引く
- [ ] 判定帯の部品と配線（「部品位置」「配線」節の判定帯ぶん）
- [ ] **検証①** 冷状態で X=12V、Q2コレクタ≒1V
- [ ] **検証②** NTCを指で温めて X=0V、Q2コレクタ=12V
- [ ] **検証③** NTCの線を片方外して X=0V に落ちる
- [ ] VR2 のwiperを 2.0V に調整
- [ ] 電力帯の部品と配線（Q1・R5・セル出力端子台）
- [ ] 降圧コンバータ単体で出力を 5.0〜5.2V に調整 ← **Picoに繋ぐ前**
- [ ] INA260のソケット
- [ ] 端子台4個とD1、および筐体内の降圧コンバータとの結線
- [ ] 信号ヘッダ 2×5 とINA260のロジック4本、Xの分圧モニタ配線
- [ ] ヒューズ 1A スローブローを挿入
- [ ] NTC#1をアルミ板に貼ってから VR1 を42℃で現物合わせ

**未検証**：42℃での切り替わりもヒステリシス幅3.1Kも実測していない。NTC自己発熱がアルミ板接着でどこまで下がるかは計算で見積もっただけで、較正に吸収されるという前提の確認も未了。降圧コンバータ用の端子台2個の座標（[3,15]・[5,15]・[9,15]・[11,15]）は空いた領域へ機械的に割り当てただけで、分岐帯3個の電線の向きとあわせて、筐体内のどこに降圧コンバータと制御基板が座るかが決まらないと確定しない（[[enclosure_design]]に基板の据付位置の記述がない）。INA260の[15,20]〜[22,20]も、8パッドのシルク順を現物で確認していないため、どのピンがどの穴かは未定。信号ヘッダの箱型シュラウドが行1の下端クリアランス約5.5mmに収まるかも未確認。

セル出力端子台と5V出力端子台のGND側は当初どこにも繋がっていなかったが、`[33,19]→[33,25]`と`[25,15]→[9,15]`で解決済み。**バスを[32,19]で切ったあと[31,19]↔[33,19]が開放になっていることの実測確認だけは、通電前に必ず取ること。** あわせて、配線節の`[9,15]→判定GND`によりPicoの5V戻り電流（Pico単体50mA、Pi Zero 2 Wを足すと385mA）が判定GNDへ流れ込む構成になっている。パルスではなく定常電流なので現物合わせの較正に吸収される見込みだが、Piを足した構成でも閾値が動かないことは確認していない。信号ヘッダのGNDも判定GNDに落ちるため同じ経路に乗る。

node_Tにはフィルタコンデンサがない。C1（判定12V）・C2（V_ref1）・C3（X）はあるが、いちばん長いセンサ線の先だけ素通しになっている。熱の応答は秒オーダーなので100nF程度なら遅延は問題にならず、DC的な話である断線検出も壊さない。検証②③の実測を見てから足すかどうか決める。

Xノードの分圧モニタをPicoのGP18で読む部分は、RP2350エラッタE9の条件下での挙動を確認していない。
