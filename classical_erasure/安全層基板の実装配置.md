# 安全層基板の実装配置

プレートが熱くなりすぎたときに、ソフトウェアを介さず電源そのものを切る回路の作り方をまとめたもの。温度センサの線が外れた場合や部品が壊れた場合も含めて、**どこが異常でも必ず「切る」側に倒れる**ようにしてある。95×72mmのユニバーサル基板1枚に、どの穴へ何を挿すかまで書いてある。

関連文書：機能ブロックと設計原則は[[architecture]] 3.4節、部品表と熱設計は[[components]] 4節、制御基板側の回路図は[[circuit_schematic]]、異常時の倒れ方の指摘は[[implementation_risks]]。

---

## インバータ段を入れる

[[components]] 4節が「1センサ構成のままにするか、インバータ段を足すかは未決定」としていた点を、**インバータ段を入れる**方に決めた。追加はNPN 1個と抵抗2本だけで、これがないと次の3つの故障がすべて「遮断されない側」に倒れる。

| 故障 | インバータなし | インバータあり |
|---|---|---|
| NTC断線 | 「冷たい」と読めて遮断されない | 遮断 |
| コンパレータ出力のLOW固着 | 遮断されない | 遮断 |
| 2個目のNTCによる冗長化 | ワイヤードANDになり両方が検知しないと切れない | どちらか1つで切れる |

却下したのは**コンパレータ出力でPchゲートを直接駆動する案**である。部品は減るが、**1つのしきい値では過熱とNTC断線の両方を捕まえられない**。NTCは断線すると抵抗が無限大になり、これは常に「いちばん冷たい」側の電圧に対応する。過熱で振れるのは反対側なので、分圧の上下を入れ替えても片方しか取れない。参加者が触れる装置の最後の砦である以上、この非対称は許容できない。

インバータを入れると、余っていた**TA75393Pのもう片方の回路をNTC断線検出に使える**ようになり、1個のICで両側を挟める。

## 回路

```
12V ─┬─ NTC#1 ─┬── node_T ──┬── R1 10k ── GND
     │          │            ├── U1 pin2 (IN A−)   過熱検出
     │          │            └── U1 pin5 (IN B+)   断線検出
     ├─ VR1 ── wiper ─┬─ U1 pin3 (IN A+)   7.81V ≒ 42℃
     │                └─ R2 100k ── X       ヒステリシス 3.1K
     ├─ VR2 ── wiper ─── U1 pin6 (IN B−)   2.0V ≒ 断線判定
     ├─ U1 pin8 (VCC)、C1 100nF を pin8–pin4 間に
     ├─ R3 10k ── X                         Xプルアップ
     ├─ R5 10k ── Q1 gate                   ゲートプルアップ
     └─ Q1 source

U1 pin1 (OUT A) ─┬─ X ─┬─ C3 100nF ─ GND   起動遅延・ノイズ除去
U1 pin7 (OUT B) ─┘      └─ R4 10k ─ Q2ベース

Q2 2N3904: エミッタ→GND、コレクタ ─ R6 1k ─ Q1 gate
Q1 drain ─ INA260 ─ +12V_cell → 制御基板
```

正常時のみ両コンパレータが開放してXが12Vになり、Q2が導通してゲートを引き下げ、Q1が通電する。過熱・NTC断線・NTC短絡・コンパレータ故障のいずれでもXが落ち、R5がゲートを12Vへ持ち上げて遮断する。**全系統が正常なときだけ通電する**向きになっている。

分圧は `12V → NTC → node_T → 10k → GND` の向き（NTCが上）。103AT-11（B=3435）の計算値で42℃＝7.81V、感度90mV/K、0℃＝3.10V。V_ref2を2.0Vに置けば正常温度域を誤検知せず、断線（0V）だけを拾える。NTC短絡（12V）は過熱側のコンパレータが拾う。

**R2は100kΩ**。[[components]] 4節の「100kΩで3.1K」はトリマ側（テブナン2.4kΩ）へ帰還させる前提の値で、この構成はそのとおりになっている。帰還先をnode_T側（テブナン3.5kΩ）に変える構成では150kΩが必要になるので、値だけ流用してはならない。

C3は起動時の保険でもある。R3との時定数1msでXの立ち上がりが遅れるため、コンパレータが判断を終える（µsオーダー）まではQ1が入らない。

## 基板と座標系

秋月 AE-B2 TH、95×72mm、**35列 × 25行**。座標は **[列, 行]** の順で書く。**[1,1]が左下、[35,25]が右上**。1つ目は1〜35、2つ目は1〜25までしか取らないので、2つ目が26以上なら読み違えである。

部品は番号のない面に挿し、**バスと配線は番号のある面**に置く。配線が30本近くあり、その大半が空き穴どうしを結ぶ作業で座標を必要とするため。裏返すと列1が右端に来るので、作業前に[1,1]の角へ油性ペンで印を付けておく。

**node_TがU1のpin2とpin5、トリマがpin3とpin6**である。直接駆動案とは逆なので、値だけでなく入力の割り当てごと読み替えてはならない。

NTC#1をコネクタにしないのは、断線検出を入れてもなお、抜けやすい接続を作る理由がないため。

**INA260**は片側1列の8パッドにピンヘッダを立て、ソケットへ垂直に挿す。占有は8穴で高さが約18mm伸びる。電流経路はネジ端子とVIN+/VIN−パッドが並列なのでパッド側だけ使えばよい（流れるのは約70mA）。VIN+がQ1側＝上流、VIN−が制御基板側＝下流で、逆にすると$\int VI\,dt$の積算が負になる。**ロジック電源は必ず3.3V**（Picoの36番）から取る。5Vを入れるとI2Cのレベルが5VになりGP20/GP21を壊す。I2Cプルアップはブレークアウト側に載っている。

**降圧コンバータ**の+VINは**Q1より上流の12V_INバス**へ繋ぐ。安全系がセルを遮断してもPi/Picoは動き続ける必要があるため（[[circuit_schematic]] 3節）。出力はD1経由でPicoの**VSYS（39番）**へ。VBUS（40番）はUSBの5Vに直結しているので外部電源を繋ぐとホスト側を壊す。

D1は1Aショットキーで足りる。この位置を流れるのは5V側の負荷電流だけで、Pico単体なら約50mAしかない。仮にショットキーでなく普通のシリコンダイオードでも、VSYSは1.8〜5.5Vを受けるので0.7V降下しても動作する。

## 調整と保護

**降圧コンバータの出力は、Picoに繋ぐ前に必ず合わせる。** このモジュールは可変出力で初期位置が不定であり、12V近くがそのまま出ることもある。出力側に何も繋がない状態で12Vを入れ、テスターでVOUT+とVOUT−の間を測りながら**5.0〜5.2V**にしてから接続する。5.2VにすればD1の降下を引いてVSYSが約4.9Vになる。上限は5.5V。表示器の値は目安で、確定はテスターで取る。

**トリマは通電した正常（冷）状態で調整する。** R2の帰還がV_ref1をわずかに持ち上げるため、無通電で合わせるとずれる。VR2を先に2.0Vへ、VR1は後からアルミ板にNTCを貼り、基準温度計と突き合わせて42℃で切り替わる点に合わせる。計算上のwiper電圧7.81Vは出発点にすぎない。合わせたらネジにホットボンドを一滴垂らして固定する。設営の振動でハードカット温度が動くと安全機構の意味が薄れる。

**ヒューズは2Aではなく1Aスローブロー。** アダプタが12V 1.5Aなら、2Aのヒューズは基板が短絡してもアダプタ側の保護が先に落ちるだけで保護にならない。通常消費は約110mA（Pico単体構成）で、Pi Zero 2 Wを足しても385mA。スローブローにするのは降圧コンバータの入力コンデンサへの突入で誤って飛ぶのを避けるため。セル側のバルク30µFへの突入は、Q1が起動時にOFFから始まるので電源投入の瞬間には流れない。

NTC#1は12V駆動で約3.3mWを消費し、静止空気中なら2K以上の自己発熱誤差になる。アルミ板に熱伝導接着すれば実効放熱定数が上がって実害は小さくなり、いずれにせよ現物合わせの較正に吸収される。**板に貼った状態で調整すること**が条件になる。

## 組立順と途中検証

順序の原則は[[components]] 8節と同じで、**背の低い部品から**、**不可逆な工程と壊れうる工程を後ろに回す**。この基板に固有の要点は、**判定帯だけを先に完成させてQ1を載せる前に検証を通す**ことにある。判定帯が正しければコンパレータ出力を見るだけで全異常が確認でき、その段階では電力段が存在しないので、配線を間違えていても壊れる部品がない。

以下は雛形であり、チェックの状態は各自の手元で付ける。

- [ ] バス7本を引く（電力GND / 12V_IN / ドレイン / 判定12V / 判定GND / V_ref1 / X）
- [ ] スター接地 `[4,5]→[4,25]` を1本だけ引く
- [ ] 判定帯の受動部品（R1・R2・R3・R4・R6・C1・C2・C3）
- [ ] 判定帯の能動部品（U1は切り欠きを右、VR1、VR2、Q2）
- [ ] **検証①** 冷状態で X=12V、Q2コレクタ≒1V
- [ ] **検証②** NTCを指で温めて X=0V、Q2コレクタ=12V
- [ ] **検証③** NTCの線を片方外して X=0V に落ちる
- [ ] VR2 のwiperを 2.0V に調整
- [ ] Q1（タブ=ドレイン、寝かせてネジ留め）と R5
- [ ] 降圧コンバータ単体で出力を 5.0〜5.2V に調整 ← **Picoに繋ぐ前**
- [ ] INA260ソケット、D1、端子台
- [ ] ヒューズ 1A スローブローを挿入
- [ ] NTC#1をアルミ板に貼ってから VR1 を42℃で現物合わせ
- [ ] VR1・VR2 のネジをホットボンドで固定

検証①〜③は12Vだけを入れて行う。

| 見る場所 | 冷 | 温（42℃超） |
|---|---|---|
| X（[26,8]） | 12V | 0V |
| Q2コレクタ（[30,6]） | 約1V | 12V |

**検証③がこの構成の存在理由そのもの**である。NTCの線を外してXが落ちることは、直接駆動案では原理的に起こらない。ここが取れなければインバータ段が働いていないので、Q1を載せてはならない。

---

**未検証**：実機を組んでいないため、42℃での切り替わりもヒステリシス幅3.1Kも実測していない。NTC自己発熱がアルミ板接着でどこまで下がるかは計算で見積もっただけで、較正に吸収されるという前提の確認も未了。降圧コンバータの寸法は写真からの換算値（約28×50mm）で、実測していない。INA260の8パッドの並び順もAdafruit標準の推定で、刻印との突き合わせが済んでいない。Xノードの分圧モニタをPicoのGP18で読む部分は、RP2350エラッタE9の条件下での挙動を確認していない。
